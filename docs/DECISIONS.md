# Qərarlar

- TypeScript 6.0.3 seçildi (7.x typescript-eslint tərəfindən hələ dəstəklənmir); `@dicebear/core` 9.4.3 (`@dicebear/collection` 9.x ilə uyğun).
- Avatar üslubları: `fun-emoji`, `adventurer` (CC BY 4.0), `bottts` (pulsuz istifadə) — atribut “Haqqında” pəncərəsindədir.
- Plitə rəngləri C/D/F kontrast ≥ 4.5:1 üçün tündləşdirildi: `#B45309`, `#047857`, `#BE185D`.
- Çox seçim xalı: hər düzgün variant `basePoints × sürət / düzgünlərin sayı`, hər səhv eyni qədər azaldır, min 0; “düzgün” (seriya üçün) yalnız tam uyğunluqda.
- “Cavabı yaz”: həm az-AZ (I→ı), həm en-US (I→i) kiçik hərf qaydası ilə müqayisə; durğu işarələri nəzərə alınmır.
- `questionStartedAt` serverTimestamp ilə yazılır, sonra serverdən oxunub `questionEndsAt` əlavə edilir (ikinci yazı); bu arada cavab plitələri deaktivdir.
- Host vaxt bitdikdən 1,5 s sonra (Rules +2 s icazə verir) və ya hamı cavab verəndə xalları hesablayır.
- Pauza zamanı `questionEndsAt = null` → Rules cavabları rədd edir.
- Variantlar oyunçuya görə (uid+sual) qarışdırılır, rəng/forma isə variantın özünə bağlıdır — host ekranı ilə uyğun gəlsin.
- `answeredCount` hər cavabda yox, yalnız reveal-da yazılır (oxuma kvotasına qənaət); host canlı sayı `answers` dinləyicisindən alır.
- Oyun bitəndə suallar + düzgün cavablar `games/{id}.review`-a yazılır ki, oyunçular “Cavablarıma bax” edə bilsin.
- `self` (öz tempində) rejimi, power-ups və komanda rejimi hələ edilməyib (M6, istəyə bağlı).
- Sessiya branch qaydasına görə iş `claude/quirky-galileo-mk297c` branch-ində aparılır; `main`-ə merge istifadəçinin təsdiqi ilə.
- Firebase web config koda standart dəyər kimi yazıldı (ictimai məlumatdır, Rules qoruyur); env dəyişənləri varsa, onlar üstünlük alır. Səbəb: Vercel-də env olmadan da işləsin.
- 50/50 güc artırıcısı: oyunçu `power` sahəsini yazır, host gizlədiləcək səhv variantları yalnız həmin oyunçunun sənədinə (`fiftyHide`) yazır — düzgün cavab heç vaxt ictimai sənədə düşmür.
- Güc artırıcı inventarını yalnız host azaldır; oyunçu yalnız `power` seçimini dəyişə bilər (Rules ilə yoxlanılır). Hər oyunçuya oyunda hər birindən 1 ədəd.
- Sual önizləməsi `countdown` fazasında `preview` sahəsi ilə göstərilir (min. 3 s); köhnə 3-2-1 geri sayımını əvəz edir.
- “Haqqında” pəncərəsi girişdən çıxarıldı; DiceBear atributu Admin → Ayarlar səhifəsinin altında saxlanır (CC BY 4.0 tələbi).
- Admin `/admin` artıq Paneldir, quizlər `/admin/quizzes`-dədir.
- Öz tempində rejimi: `games/{id}/starts/{uid_q}` (yalnız bir dəfə yazılır) sualın başlama vaxtını server vaxtı ilə qeyd edir; host hər cavabı gəldikcə qiymətləndirir və fərdi nəticəni (düzgün cavab daxil) yalnız həmin oyunçunun sənədinə yazır.
- Avtomatik rejim host klientində işləyir (host ekranı açıq olmalıdır); keçid ən son `next` funksiyası ilə ref vasitəsilə çağırılır.
- Düz/səhv cavab səs parçaları Firebase Storage olmadan (Spark planı) Firestore-da `sounds/{correct|wrong}` sənədlərində mono 16 kHz WAV data-URL kimi saxlanılır (≤ 8 s ≈ 350 KB).
- Müəllif hüquqlu mahnı parçaları platformaya daxil edilmir; admin istifadə hüququ olan faylı özü yükləyir.
- Təlimçi profili `profiles/{uid}`-də saxlanılır (hamı oxuyur, yalnız sahibi admin yazır); oyun yaradılanda `games/{id}.host`-a kopyalanır.
- Host "heartbeat"-i ayrıca yazılmır (N oyunçu × hər 10 s oxuma kvotası olardı); oyunçu sualın vaxtı keçdikdən 10 s sonra faza dəyişməyibsə xəbərdarlıq görür.
- Lobbi massivi son 60 nəfərlə məhdudlaşdırılır, `playerCount` tam saydır; debounce 1,2 s.
- Rollar `admins/{uid}.role`-dadır (`owner` | `trainer`). Yeni təlimçi hesabı müvəqqəti ikinci Firebase tətbiqi ilə yaradılır ki, sahibin sessiyası dəyişməsin.
- Reaksiya sənədinin id-si `uid_<2 saniyəlik pəncərə>`-dir; Rules həm cari, həm əvvəlki pəncərəni qəbul edir (saat fərqinə dözümlülük).
- Tapşırıq rejimində suallar ictimai sənəddədir (rəqabət yoxdur, güc artırıcılar söndürülür); qiymətləndirmə təlimçinin brauzerində "Qiymətləndir və yekunlaşdır" ilə aparılır.
- Şəkillər Storage olmadan WebP data-URL kimi (≤ ~280 KB) sual sənədində saxlanılır.
- `adventurer` avatar üslubu (~400 KB) yeni seçimdən çıxarılıb, əvəzinə `big-smile`; köhnə oyunlar üçün tənbəl yüklənir.
- İngilis dili: `t` modul yüklənəndə seçilir, dil dəyişəndə səhifə yenilənir (sadəlik; bütün komponentlər `t`-ni birbaşa istifadə edir).
- e2e testləri real layihəyə yazır; buna görə tam oyun testi yalnız sirr kimi verilən test hesabı ilə işləyir.
